# cufely-landing

Static landing page for [Cufely](https://cufely.com), an electronic invoice ingestion and reconciliation tool for accountants and small businesses in Colombia.

The product itself is developed in [conciliador-fiscal](https://github.com/MarlonJara-S/conciliador-fiscal). This repository only holds the public website.

## Structure

- `index.html`: the whole page (HTML and CSS, no build step).

## Deploy

Hosted on Cloudflare Pages, connected to this repository. Every push to `main` publishes the site.

## Local preview

Open `index.html` in a browser.
